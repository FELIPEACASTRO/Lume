Controle local de API keys pendentes

Use este painel para acompanhar quais credenciais ja foram criadas, inserir valores localmente, montar o bloco .env e marcar o teste concluido. O navegador salva apenas checklist e observacoes. Os segredos digitados ficam somente nesta sessao.

Importe um .env atual ou cole pares ENV=valor.
Os segredos digitados nao vao para localStorage.
Fluxo recomendado
  • Abrir o portal do provider.
  • Gerar a credencial e marcar Chave criada.
  • Preencher os campos ou importar o .env.
  • Revisar ou baixar o bloco consolidado.
  • Executar o teste no backend e marcar Teste OK.
